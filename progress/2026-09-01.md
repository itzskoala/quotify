# 2026-09-01 — Onboarding redesign

## TL;DR

Rebuilt onboarding from a 7-question quiz into a 5-screen, benefit-first flow:
**core value → pick your moods → subscription paywall (mock) → sign up/log in
(mock) → daily notification time (custom wheel picker)**. Installed the
`impeccable` design-skill plugin. Committed and pushed the whole project to
GitHub for the first time (`github.com/itzskoala/quotify` — you're renaming
it to `quotable`).

## What changed

**Onboarding (`src/components/onboarding/`)**
- **Welcome** — rewritten copy: "Daily Wisdom for Your Mind," benefit-framed
  subtext instead of a feature description.
- **Categories** *(new)* — tap-to-select mood/topic pills, reusing the app's
  real Explore mood board taxonomy (motivation, workout, romance, anime,
  movies, calm, wisdom) instead of a made-up list, so this screen actually
  drives something (tone of the live-generated quote, and it's stored for
  future personalization).
- **Paywall** *(new)* — weekly / yearly plan cards, benefit-led copy,
  "Continue" + "not now." **Mock only** — no real purchase flow.
- **Account** *(new)* — sign up (name + email + password) or log in, backed
  by a local mock account stored on-device. **Not real auth** — no backend,
  no password verification against a server.
- **Notify time** *(new)* — a custom-built scroll-wheel time picker (hour /
  5-min / AM-PM), with the center row full-strength and rows above/below
  fading and shrinking. Built by hand with Reanimated rather than a native
  picker library, so it works the same on iOS, Android, *and* web.
- **Deleted**: the old goal / entry-reason / experience / life-focus / vibe /
  favorite-thinkers screens — none of their answers were consumed anywhere
  outside onboarding, so this was a clean removal, not a breaking change.

**Data model** (`constants/quotable.ts`, `constants/library.ts`,
`lib/storage.ts`, `lib/notifications.ts`, `providers/app-state.tsx`)

## Things to watch for

- The paywall's selected plan **isn't persisted anywhere** yet — it's
  visual-only. If/when real IAP goes in, that's new plumbing, not something
  already half-wired.
- Mock auth has **no real security** — the "password" is a simple local hash
  with a loud comment saying so (`mockHash()` in `app-state.tsx`). Don't let
  this pattern leak into anything that matters before a real backend exists.
- `resetOnboarding()` (dev-only, used from the Me tab) clears onboarding
  flags but **keeps the mock account** on purpose, so you can re-run the
  flow and hit the "log in" path instead of always signing up fresh.
- The wheel picker's row count assumes 12-hour/5-minute steps; if you ever
  want 1-minute precision, check `wheel-time-picker.tsx`'s `MINUTES` array
  and `ITEM_HEIGHT`/`VISIBLE_ROWS` constants before changing the data shape.
